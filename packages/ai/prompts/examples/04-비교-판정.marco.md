# slide id=stateless-vs-spi
tag: 2부 · 검사 엔진
title: 2세대 방화벽은 대화의 흐름을 기억한다
question: 요청은 나가는데 웹페이지가 열리지 않는 이유는?
time: 3분

:::compare left="1세대 · Stateless" right="2세대 · SPI"
보는 것 | 패킷 한 장의 주소·포트 | 패킷과 상태 테이블의 연결 기록
응답 패킷 | 돌아오는 방향 규칙을 따로 써야 한다 | 나간 요청의 응답이면 규칙 없이 통과한다
운영 부담 | 반환 규칙을 넓게 열면 상시 개방이 된다 | 규칙은 요청 방향만 쓴다
:::

:::verdict drop 1세대
서버의 SYN-ACK 응답 → 맞는 규칙 없음 → 폐기된다.
:::

:::verdict allow 2세대
같은 SYN-ACK 응답 → 상태 테이블과 일치 → 통과한다.
:::
